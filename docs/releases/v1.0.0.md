# Music Man v1.0.0 — first release

Paste a playlist link. Get music you'll actually like.

## What's in v1

- **Playlist intake** — Deezer and YouTube Music links (beta), 500+ tracks
  fully loaded with pagination
- **Recommendation engine** — Last.fm-powered: 30–150 songs + 5–30 albums
  per run, every pick explained in plain English
- **Discovery controls** — 28 genre chips, 7 mood chips, and Surprise me
  (no seed playlist needed)
- **Library** — favorites with daily picks, full run history, saved
  playlists with rescan, JSON export
- **News tab** — 9 RSS sources with a For You feed ranked by your taste,
  offline cache included
- **Open anywhere** — outbound links to Spotify, Deezer, YouTube,
  YouTube Music (no auth needed)
- **Private by design** — no accounts, no servers, no tracking; all data
  stays on-device

## Notes

- Spotify *intake* is parked for v1 (Spotify's Dev Mode policy now
  requires Premium on the dashboard account); outbound Spotify search
  links work without auth.
- Desktop builds are for UI testing only; share-intent receiving needs
  Android.
